ขั้นตอนการนำขึ้น GitHub Pages สำหรับแสดงผลสาธารณะ

สำหรับนักสาธารณสุข: ท่านสามารถใช้ GitHub Pages เพื่อโฮสต์ Dashboard นี้ออนไลน์โดยไม่มีค่าใช้จ่าย และสามารถอัปเดตข้อมูลผ่าน Google Sheets CSV ได้แบบ Real-time!
  1. เซฟไฟล์นี้เป็น index.html บนคอมพิวเตอร์ของคุณ
  2. สร้าง Repository ใหม่บน GitHub:

    เข้าเว็บไซต์ GitHub.com -> กดปุ่ม "+" ด้านบนขวา -> เลือก "New repository" ตั้งชื่อ เช่น epi-dashboard แล้วเลือก Public

  3. อัปโหลดไฟล์ index.html:

    ในหน้า Repository กดปุ่ม "uploading an existing file" แล้วลากไฟล์ index.html ใส่เข้าช่องอัปโหลด จากนั้นกด "Commit changes"

  4. เปิดใช้งาน GitHub Pages:

    ไปที่เมนู Settings ของ Repository -> เลือกแถบ Pages ด้านซ้าย -> ในส่วน Build and deployment ให้เปลี่ยน Source เป็น Deploy from a branch -> เลือก Branch เป็น main (หรือ master) -> กด Save

  5. เสร็จสิ้น! รอประมาณ 1-2 นาที GitHub จะให้ลิงก์ URL สาธารณะ เช่น https://username.github.io/epi-dashboard/ สามารถส่งให้ผู้บริหารหรือทีมสาธารณสุขเข้าดูได้ทันที
